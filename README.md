# Bank Management System - C++

A comprehensive console-based Bank Management System developed in C++. This project demonstrates the practical application of Object-Oriented Programming (OOP) principles, clean code architecture, and robust data management.

## 🚀 Overview
The system provides a complete environment for managing banking daily operations, including client handling, secure transactions, user permission management, and a dedicated currency exchange module.

## ✨ Key Features

### 1. Client Management
- Full CRUD operations (Create, Read, Update, Delete).
- Advanced search functionality by Account Number.
- Real-time data validation for all inputs.

### 2. Transactions Module
- Deposit & Withdraw: Handle balance updates securely.
- Transfer: Move funds between clients with automated balance checks.
- Transfer Log: A detailed history of all fund transfers.
- Total Balances: Summary report of all bank holdings.

### 3. User & Security Management
- Permissions System: Granular access control for different users.
- Secure Login: Multi-trial login system to prevent unauthorized access.
- Login Register: Tracks user activity including timestamps and credentials.

### 4. Currency Exchange Module
- Real-time currency data management.
- Currency Calculator: Tool for converting between international and local currencies.
- Update exchange rates functionality.

## 🛠 Tech Stack
- Language: C++
- Paradigm: Object-Oriented Programming (OOP)
- Architecture: Multi-layered headers (Classes-based)
- Storage: File Handling (Text/Data files)
